禁欲，应该是可以大大加快开发速度的方式。

不仅是不射精，更重要的，是完全戒断视觉刺激。（可能戒断短视频和游戏，也有辅助作用）

## 为什么要禁欲

**视觉是一种无法导向高潮的性感带。**
当我们说这句话的时候，我并不是在说我们无法通过观看来自动达成高潮。而是在描述视觉对于**内生快感**的影响。当我们获得视觉刺激的时候，我们是在刺激性感带。男性很早便养成了需要视觉刺激辅助自慰的自慰习惯。这导致当我们过长时间观看色情内容后，需要更加刺激的内容去刺激自己的视觉来获得更多的多巴胺。这会导致**快感和高潮阈值的提高**。我们所追求的雌性高潮是一种内生的，只需要少量外界刺激的高潮方式。——[Lilithbell](https://bbs.viva-la-vita.org/d/14575/3)

**禁欲，也是在积攒性能量。**

想想，如果辛辛苦苦积攒的性能量，如果用射精一下子短时间内就释放了，未免也太可惜了吧~（参见[「点数理论」](https://wiki.viva-la-vita.org/general/theory#%E7%82%B9%E6%95%B0%E7%90%86%E8%AE%BA)）

其次，色情视频中的镜像神经元，即使是里面的女性，因为表演，也往往是使用偏向雄性高潮的那种爆发性的模式，因此即使我们希望代入其中的女性角色，也容易进入「雄性高潮」的模式，而不是我们希望开发的，更渐进式、发散式的雌性高潮。

此外，视频也容易让我们失去想象的能力。

## 禁欲的效果

禁欲1~3天，身体就更容易进入「性感或发情」状态。

论坛中不同人会有不同的感受，比如「全身酥麻」、「敏感到想哭」。（这部分仍然有待收集更多数据）

### 出现戒断反应，怎么办？

如果当因为强烈的戒断，而饥渴难耐时，这时就可以玩玩乳首了。「呼吸扩散」技巧，也可以有效地帮我们缓解不适，并且引导性能量，转向新的性感带。

（注：这篇文章的经验，主要来源于男生；对于女生的情况，还有待更多研究）
