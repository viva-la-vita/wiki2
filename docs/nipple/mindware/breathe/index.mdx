呼吸扩散方法，是将性能量和局部刺激，转化为全身雌潮的关键方法。

### 大致要领

**步骤一（呼气）：** 呼气时，对乳首进行物理刺激。

**步骤二（吸气）：** 停止所有刺激。深深吸气，想象着电流和快感扩散开来，感受性能量流向全身。

### 为什么呼吸扩散法有用？

其实很多催眠音声，在开头引导催眠时，用得最主要的方法，也是「深呼吸」了。

大致是，在白天，在皮质醇较高时，或者一般的雄性高潮时，是交感神经主导。交感神经，是一种与战斗相关的神经，如果交感神经主导，就会压制副交感神经。副交感神经，才是主导雌潮的神经模式。

而深呼吸，就可以帮助身体，从交感神经主导的模式，切换成副交感神经主导的模式，让全身都放松下来，进入舒舒服服的状态。
