1. 压力相关型
    原理：
     ①触发：物理条件上直接满足排尿触发条件
     ②原理：膀胱受压后，尿道阻力下降
     ③感受：能明显感觉尿意，在身体放松后可开始潮吹，力度可弱可强
    常见情形：
        男性/女性：直接压力刺激（即通过炮机刺激到膀胱区域达到潮吹）

2. 神经反射主导型
    原理：
        ①触发：对于与骨盆神经有关的性敏感区域的极强烈刺激
        ②原理：一个可能的逻辑链是 性刺激 → 副交感兴奋→外尿道括约肌张力下降→排尿反射被触发
        ③感受：有明显对抗感，潮吹过程的感觉更偏强制，即失控般地以非常大的力度喷出或射出液体
    常见情型：
        男生：龟头强刺激下带来的潮吹
        女生：阴蒂强刺激下的潮吹、后庭自慰带来的潮吹

3. 阈值降低型
    原理：
        ①触发：长时间高强度的高潮
        ②原理：高度性唤醒状态下，快感与高潮占据了主要的感受空间，对排尿相关信号的感知与抑制能力下降，同时在极度快感下对失禁的心理阈值降低，最终无意识潮吹
        ③感受：一般情形为在高潮爽到恍惚之后很久才回过神来，发现已经流出了大量液体
    常见情型：
        男生：较难达到（由于生理结构的局限）
        女生：极少数催眠高潮及部分花心高潮
    
    *注：该类型目前**缺乏明确的生理机制证据**，部分情况可能与主动或半主动排尿存在界限模糊，仅供参考*

4. 多重混合型
    原理：
        即前三种的混合结果。在实际情况中，纯单一机制的案例较少，多数表现为不同机制的叠加，其中某一机制占主导地位，但其他机制也不容忽略，便归类为混合型。
    常见情型：
        男生：较难达到（由于男性尿道长度、前列腺位置及刺激路径的原因，较难同时满足持续压力与反射触发条件）
        女生：
        1.G点高潮（以对膀胱的压力为主，也有部分心理因素及神经反射的作用）
        2.花心高潮（作为目前许多女性认可的人体最深度高潮，往往大部分花心高潮都伴有明显的喷水现象，其部分是因为极度快感导致阈值下降，也有部分原因是神经反射所导致）
