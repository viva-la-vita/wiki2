3.界定核心：这个定义的三个核心就是“性刺激”“（近乎）非主动”“大量透明液体”：  

（1）“（近乎）非主动”：在前言中便提到 本版块提到的潮吹更具有性开发类的性质   
这里列举一些不纳入讨论范围的情况：  
a.主动的潮吹 实际上就是主动排尿 与性开发没有太大的联系（与其有一定区别但容易混淆的是在极度的性快感下不自觉的漏尿 在部分讨论中有争议 但本文将其纳入讨论范围 将在后文的“阈值下降类”中加以阐述）  
b.无性刺激下的排液（如白带等）  
c.仅少量腺体分泌，未形成大量喷射的现象（如男性尿道球腺液，女性前庭大腺液等）  
d.非性刺激导致的尿失禁  

（2）.同时也由此可推出 作为非自发的行为 必然是有外界的刺激的 显然应当是“性刺激”使其拥有了可行性 ++（让我们先姑且忽略那些天生极度敏感的天赋怪）++  

（3）.至于为何是“大量透明液体”：首先基于上文论述的概念起源 不难发现这个概念的最常见 也是最原始的现象便是女性从尿道口喷出大量澄清透明液体 因此将其作为基本定义 在后续“液体成分”章节论述潮吹液体构成时会进一步阐释
