### 3.1 本章核心  
**本章的目标是研究清楚潮吹的液体的组成。其组成向来是一个热门的话题，从1981年Addiego et al.的研究提出女性在高潮时可以排出少量非普通尿液的液体起，生理学界围绕有关潮吹的讨论就一直很热门。在此，我们从女性与男性两种生理性别出发，分别研究其潮吹机制。**  


### 3.2 一些常见观点  

**首先，就女性而言，目前有相对较多的科研研究了女性潮吹的机制。目前主流的观点认为女性的“喷水”广义上包含了“女性射精”（female ejaculation）、“潮吹”（squirting）、“性交性尿失禁”（coital incontinence）与阴道润滑液。由于后两者并不属于今日我们讨论的范畴，因此只主要考虑前两者。**  

**“女性射精”的概念这里是第一次提到，因而稍微加以阐述。其液体量较少，一般认为来自尿道旁腺（亦称“斯基恩氏腺”）。这**是一种**位于女性尿道下端两侧的小腺体**，在胚胎发育上与男性前列腺同源，能在性兴奋时分泌液体。而检测这种尿道旁腺液，就是靠其表达的前列腺特异抗原（PSA）。这一结论源于2011年的相关研究，也为“女性射精”与“潮吹”的区分提供了重要标准。  

**值得注意的是，在2015年的一项研究中，通过超声与尿素检测，对7名可以反复做到大量排出液体的女性进行了研究，得到的结果是：排液前膀胱明显重新充满，而排液后又明显排空，且排出液体与尿液样本在尿素、肌酐、尿酸等多方面都有相似特征。但同时，其中5人的排液样本中也检测到了PSA。因而，得到结论是，排液的本质主要是膀胱中的尿液性液体，其中往往存在来自尿道旁腺的少量分泌物，是为“潮吹”与“女性射精”的结合。**  

**而在后续2022的一项研究中，通过给膀胱中液体染色的方法，再次证明了潮吹的液体主要来自膀胱。同时，在5个研究样本中有4人的排出液都呈PSA阳性。**  

**由此，我们便可认识到，女性真正的“潮吹”，大部分由膀胱中的尿液构成，少部分来自尿道旁腺液，再加以阴道正常分泌的润滑液。**  


**其次，我们再来考虑男性的潮吹。不过，相关科研文献远少于对女性的研究，甚至实际上就只有一篇发布于2018的研究文献，甚至这篇论文本身就提出，在此之前几乎没有关于男性潮吹机制的科学文献。更令人忍俊不禁的是，研究对象只有一名25岁的男性志愿者。但是，其研究机制仍是严谨的，通过直肠超声与液体生化分析进行研究。在实验中，实验对象先正常射精，而后继续刺激，便出现潮吹的现象。根据观察，液体的肌酐浓度与尿液相近，且超声显示膀胱中的液体体积下降了约100mL，而液体流动路径可以观察到**是从**膀胱 → 前列腺部尿道 → 尿道外口。事实上，这一潮吹方式被归类为射后潮吹，但通常勃起情况下导致的膀胱颈关闭会使得难以正常排尿，此时联系前文提到的“神经反射”便可理解其原因了。再回到研究本身，研究得出的结论便是，男性的潮吹是膀胱中的尿液在强烈的前列腺和盆底肌肉收缩作用下，经尿道排出**的结果。不过，由于样本过少，可能仍需未来研究进一步提供普遍性视野。但将其作为我们在实践之前的一个简单的认识，还是尚可的。
